# ProcureFlow

ProcureFlow is an end-to-end procurement management system built using Microsoft Power Platform. The solution enables employees to create purchase requests, automatically routes approvals based on configurable business rules, integrates with Microsoft Teams and Outlook for approval actions, creates dedicated SharePoint invoice folders, and provides real-time request and invoice status tracking.

## Tech Stack

- Power Apps Canvas App
- Power Apps Model-Driven App
- Dataverse
- Power Automate
- SharePoint
- Microsoft Teams
- Outlook
- Power BI (planned)
- Copilot Studio (planned)
